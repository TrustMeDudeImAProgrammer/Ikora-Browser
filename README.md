# Ikora-Browser

A small simple web-browser.

The setup:

    pip install requests PyQt6 PyQt6-WebEngine

  Or using Venv, ( Virtual Environment )

    cd Ikora

    python -m venv Dependencies

    source Dependencies/bin/activate

    python -m pip install requests PyQt6 PyQt6-WebEngine

Then to run it,

    python Func.py

( Tested on arch linux )
